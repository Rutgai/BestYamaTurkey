Yönetim Paneli

Site verilerini düzenlemek için yönetim sunucusuna bağlanın.

Bağlantı, Netlify üzerinde çalışan yönetim fonksiyonu ile kurulur. GitHub erişim jetonu tarayıcıda saklanmaz; Netlify'ın ortam değişkeninde (GITHUB_TOKEN) durur ve istekler sunucu üzerinden yapılır.

Token henüz eklenmediyse: Netlify → Site configuration → Environment variables → GITHUB_TOKEN değerini ekleyip siteyi yeniden dağıtın. Token'ı GitHub'da Fine-grained olarak oluşturup Repository access → Only select repositories → BestYamaTurkey ve Contents → Read and write iznini verin.
